# Research-Based Feature Direction

## Core Feature List

* **Current Goal Dashboard** — One clean screen showing active daily, weekly, monthly, yearly, and lifetime goals so the user always knows what matters now; goal apps work best when they provide progress visibility, reminders, milestones, and review structure. [\[clickup.com\]](https://clickup.com/blog/goal-tracking-apps/), [\[reclaim.ai\]](https://reclaim.ai/blog/goal-tracker-apps)

* **Priority Focus System** — Let user mark goals as `Critical`, `High`, `Medium`, or `Low`, and show only the top 1–3 priorities first; productivity tools fail when they add too much cognitive load instead of reducing it. [\[taskfire.io\]](https://taskfire.io/the-ultimate-productivity-app-comparison-2025-which-task-management-tool-actually-delivers-results/), [\[guptadeepak.com\]](https://guptadeepak.com/tools/top-10-task-management-apps-2026/)

* **Goal Time Horizon** — Support `Daily`, `Weekly`, `Monthly`, `Yearly`, and `Lifetime` goals; modern goal trackers commonly support different planning styles like daily habits, quarterly goals, long-term aspirations, and project milestones. [\[reclaim.ai\]](https://reclaim.ai/blog/goal-tracker-apps), [\[clockdiary.com\]](https://clockdiary.com/blog/productivity/goal-tracking-apps)

* **Goal Breakdown into Steps** — Each goal should have small action steps/milestones because goal tracking apps are useful when they convert big ambitions into smaller measurable actions. [\[clickup.com\]](https://clickup.com/blog/goal-tracking-apps/), [\[onplanners.com\]](https://onplanners.com/apps/goal-tracking)

* **Progress Tracking** — Show percentage, completed steps, streaks/check-ins, and last updated date; progress monitoring improves goal attainment, especially when done frequently. [\[goalsandprogress.com\]](https://goalsandprogress.com/best-goal-tracking-apps/), [\[beyondtime.ai\]](https://beyondtime.ai/blog/best-goal-tracking-apps-2026-compared)

* **Achieved / Failed / Paused Status** — When closing a goal, user can mark it as achieved, failed, paused, abandoned, or retried; review and reflection are important parts of effective goal systems. [\[gettingthi...gsdone.com\]](https://gettingthingsdone.com/2025/06/weekly-review-best-practices/), [\[gtd.be\]](https://www.gtd.be/en/how-to-get-started/maintaining-the-system/weekly-reviews)

* **Failure Reflection** — If failed, ask: “Why did it fail?”, “What blocked me?”, “What lesson did I learn?”, and “Will I retry?”; weekly review systems emphasize reflecting on challenges, lessons, and next priorities. [\[loggd.life\]](https://loggd.life/tools/weekly-review), [\[gtd.be\]](https://www.gtd.be/en/how-to-get-started/maintaining-the-system/weekly-reviews)

* **Lessons Library** — Save lessons learned from failed/achieved goals so future goals can reuse them; review systems prevent repeated mistakes by capturing what worked and what should change. [\[super-prod...tivity.com\]](https://super-productivity.com/blog/gtd-weekly-review-guide/), [\[loggd.life\]](https://loggd.life/tools/weekly-review)

* **Retry Goal Flow** — Failed goal can be duplicated into a new attempt with lessons attached; goal tools should support course correction, adaptability, and accountability. [\[clickup.com\]](https://clickup.com/blog/goal-tracking-apps/), [\[reclaim.ai\]](https://reclaim.ai/blog/goal-tracker-apps)

* **Weekly/Monthly Review Mode** — A guided review screen should ask what was completed, missed, blocked, learned, and prioritized next; GTD calls the weekly review a critical success factor for keeping a trusted system updated. [\[gettingthi...gsdone.com\]](https://gettingthingsdone.com/2025/06/weekly-review-best-practices/), [\[gettingthi...gsdone.com\]](https://gettingthingsdone.com/wp-content/uploads/2014/10/Weekly_Review_Checklist.pdf)

* **Linked Notes / Planner Items** — Goals should connect with notes, tasks, planner items, PDF highlights, or projects so goals do not stay isolated from actual work. Task/goal apps are strongest when goals connect to daily actions and schedules. [\[reclaim.ai\]](https://reclaim.ai/blog/goal-tracker-apps), [\[connecteam.com\]](https://connecteam.com/best-goal-tracking-apps/)

* **Simple Goal Templates** — Add templates like “Study Goal”, “Skill Goal”, “Health Goal”, “Project Goal”, “Career Goal”, “Financial Goal”; structured goal frameworks reduce setup friction. [\[beyondtime.ai\]](https://beyondtime.ai/blog/best-goal-tracking-apps-2026-compared), [\[onplanners.com\]](https://onplanners.com/apps/goal-tracking)

# Mistakes to Avoid

* **Do not make it too complex** — Many productivity apps are abandoned because feature bloat creates more work than value; simplicity and low-friction daily use matter most. [\[taskfire.io\]](https://taskfire.io/the-ultimate-productivity-app-comparison-2025-which-task-management-tool-actually-delivers-results/), [\[goalsandprogress.com\]](https://goalsandprogress.com/best-goal-tracking-apps/)

* **Do not make goals vague** — Goal-setting research shows specific and challenging goals with feedback perform better than vague intentions. [\[strategicm...nsight.com\]](https://strategicmanagementinsight.com/tools/locke-lathams-five-principle-framework/), [\[med.stanford.edu\]](https://med.stanford.edu/content/dam/sm/s-spire/documents/PD.locke-and-latham-retrospective_Paper.pdf)

* **Do not create only a to-do list** — A real goal system needs progress, milestones, reviews, priority, and reflection, not just tasks. [\[beyondtime.ai\]](https://beyondtime.ai/blog/best-goal-tracking-apps-2026-compared), [\[clickup.com\]](https://clickup.com/blog/goal-tracking-apps/)

* **Do not hide priorities** — Users need help deciding what to work on next; simple priority levels alone are often too coarse unless paired with daily focus and review. [\[guptadeepak.com\]](https://guptadeepak.com/tools/top-10-task-management-apps-2026/), [\[saner.ai\]](https://www.saner.ai/blogs/best-personal-task-management-apps)

* **Do not skip review flow** — Without regular reviews, systems become stale, users stop trusting them, and tasks/goals slip. [\[super-prod...tivity.com\]](https://super-productivity.com/blog/gtd-weekly-review-guide/), [\[gtd.be\]](https://www.gtd.be/en/how-to-get-started/maintaining-the-system/weekly-reviews)

* **Do not punish failure** — Failed goals should become lessons and retry opportunities, not dead records; reflection-based systems emphasize learning from challenges and setting next intentions. [\[loggd.life\]](https://loggd.life/tools/weekly-review), [\[gtd.be\]](https://www.gtd.be/en/how-to-get-started/maintaining-the-system/weekly-reviews)

* **Do not force online features first** — Since Gentle Notes is offline-first, goals, priorities, reviews, and lessons should work locally without cloud dependency.
